# IP Manager for UniFi

All UniFi clients and DHCP reservations in one table: MAC, name, fixed IP, VLAN, firewall zone, connection type and issue hints.
Edit in place, use views, replace a subnet, take names from Home Assistant, import/export CSV, and save, compare
and restore versions. The firewall page shows UniFi's zone matrix and policies (read only) and warns when an IP change
affects a policy.

See the *Documentation* tab for details.
