Update names from Home Assistant

Matches Home Assistant devices to UniFi clients by MAC address. The proposed name is the name you set in Home Assistant, otherwise the device name of its integration (devices known only through the UniFi integration are skipped, they already carry the UniFi name). UniFi devices (access points, switches, gateway) and UniFi Protect cameras are shown as UniFi-managed and never renamed – their name comes from UniFi and would be synced back into Home Assistant. “Near match” means the MAC differs only in the last byte, typical for devices with separate Wi-Fi and Ethernet MACs; those are not selected by default.

Versions

A version freezes the table: names, notes, fixed IPs, AP locks, DNS records and – for information – current IP, network and first/last seen. A version is also saved automatically before every bulk action (CSV import, replace subnet, names from HA, restore). Automatic versions (daily, before bulk actions) are kept 30 days; daily versions and the retention are set in the app configuration; manual and pinned versions and the baseline are kept until you delete them.

Restore

Restore works like a CSV import from this version: you get a preview with a checkbox per row before anything changes, and a version of the current state is saved first. Devices that were added after this version are left untouched.
Limitation: a name or note that was empty in the version does not clear the current one.

Network rules

Say which devices belong in which network, e.g. Vendor contains “Espressif” → IoT. Devices that match a rule but sit in another network get the issue Expected in … (filter Issues › Wrong network). The first matching rule wins; text is matched case-insensitively.
